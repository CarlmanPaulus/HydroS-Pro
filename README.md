# HydroS-Pro v1.3.2

Hydrology tools for TROPI sites:
- **Manual Extractor** — extract manual water table data into split CSV based on site/pipes
- **RAW Combiner** — combine HOBO RAW logger files per site
- **Compiler** — combine raw diver, baro and manual water table into processing excel
- **Rainfall** — bulk QC and compile HOBO event/temperature workbooks into 30-minute rainfall data
